# Custom UDP Transport Protocol (Python)

A lightweight, educational implementation of a **custom UDP-based transport protocol** written in Python.  
This project demonstrates low-level networking, protocol design, and reliability mechanics often found in real-world transport protocols.

Designed for academic, CS, and Cybersecurity learning purposes.

---

## Features

- **Basic UDP Implementation Using The Python Core Library**
- **Complete test suite (pytest)**
- **Benchmarks** for throughput + latency
- **Full protocol specification in `/docs/protocol_spec.md`**
- **Clean architecture and documented code**
